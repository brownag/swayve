# 12.2 — Build Interactive HUD Dashboard CLI Client

## Goal
Implement a live interactive HUD dashboard CLI renderer in `swayve status --watch` that subscribes to daemon status broadcasts over Unix socket and displays a color-coded agent hierarchy tree.

## Tasks
- [x] Add `--watch` flag to `Commands::Status` in `src/cli.rs`.
- [x] Update `Commands::Panel` in `src/cli.rs` to spawn `swayve status --watch`.
- [x] Implement live watch loop in `run_cli` under `Commands::Status`: connect to `/tmp/swayve.sock`, send `daemon.subscribe` message, clear screen (`\x1B[2J\x1B[H`), and print real-time tree.
- [x] Implement `render_agent_tree` and `format_status` helper functions with ANSI color-coding (orange for `Thinking`, flashing red/bold for `AwaitingHumanInput`, green for `Completed`, gray for `Idle`, cyan for `ExecutingTool`, red for `Failed`).
- [x] Add CLI parser test `test_status_watch_cmd_parsing` in `src/cli.rs`.
- [x] Verify compilation with `cargo check` and run tests with `cargo test`.

## Notes
- Files in scope: `src/cli.rs` ONLY.
- Socket path: `/tmp/swayve.sock`.
- Message format: `serde_json::to_string(&AgentIPCMessage::SubscribeStatus)` (`{"method":"daemon.subscribe"}`).
- Zero external TUI dependencies: using std ANSI escape sequences (`\x1B[2J\x1B[H`) for terminal clearing and color codes.
