# 11.1 — Add Hook Config, Log Redirection, and Hook Execution

## Goal
Add hook configuration (`on_agent_spawn`, `on_agent_status_change`), stdout/stderr log file redirection for spawned terminals, and graceful lifecycle hook execution in the daemon.

## Tasks
- [x] Update `src/config.rs` to add `HooksConfig` struct and `hooks` field to `Config` with `#[serde(default)]`.
- [x] Add unit test for `HooksConfig` deserialization and defaults in `src/config.rs`.
- [x] Update `src/cli.rs` in `Commands::Spawn` to create `/tmp/swayve/logs` directory and redirect process stdout and stderr to `/tmp/swayve/logs/{agent_id}.log`.
- [x] Update `src/daemon.rs` to implement `execute_lifecycle_hook` helper function that spawns background shell process with `SWAYVE_AGENT_ID` and `SWAYVE_AGENT_STATUS` environment variables.
- [x] Update `register_agent` and `update_status` in `src/daemon.rs` to trigger `on_agent_spawn` and `on_agent_status_change` lifecycle hooks when configured.
- [x] Add unit tests in `src/daemon.rs` verifying hook execution behavior on agent spawn and status change.
- [x] Verify build and tests pass using `cargo check` and `cargo test`.

## Notes
- Files in scope: `src/config.rs`, `src/cli.rs`, `src/daemon.rs`.
- No modification of `src/types.rs` or other files outside scope; helper function `agent_status_to_str` converts `AgentStatus` variants to string representation within `src/daemon.rs`.
- Subprocess error handling in `execute_lifecycle_hook` uses non-blocking `.spawn()` and logs errors to stderr without panicking the daemon thread.
- Log redirection in `src/cli.rs` uses `std::fs::create_dir_all("/tmp/swayve/logs")` and passes cloned file handles for stdout and stderr to `Command::new`.
