# 6.2 — Plumb Unique app_id and Environment Variables

## Goal
Update `app_id` in `src/cli.rs` to include a timestamp suffix matching `agent_id`, and inject `SWAYVE_SOCKET`, `SWAYVE_AGENT_ID`, and `SWAYVE_PROJECT_ID` environment variables when spawning terminal processes.

## Tasks
- [x] Update `agent_id` and `app_id` generation in `src/cli.rs` (`Commands::Spawn`) to define `let suffix = now % 100000;` and set `let app_id = format!("agent.{}.{}.{}", agent, wave, suffix);`.
- [x] Add `.env("SWAYVE_SOCKET", socket_path)`, `.env("SWAYVE_AGENT_ID", &agent_id)`, and `.env("SWAYVE_PROJECT_ID", &project)` to `Command::new(&config.terminal.default_emulator)` in `src/cli.rs` (`Commands::Spawn`).
- [x] Run `cargo check` to verify compilation.

## Notes
- Discovered in Phase 1: `Commands::Spawn` in `src/cli.rs` calculates `now` and sets `agent_id` using `now % 100000` directly, while `app_id` was `format!("agent.{}.{}", agent, wave)`.
- Extracting `let suffix = now % 100000;` keeps `agent_id` and `app_id` consistent.
- `Command::new(&config.terminal.default_emulator)` at lines 184–187 will be chained with `.env(...)` methods before `.args(...)` and `.spawn()`.
- Scope is strictly `src/cli.rs`.
