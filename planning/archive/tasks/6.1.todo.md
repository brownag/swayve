## Goal
Fix Sway IPC command string formatting for `SwayCommand::SetBorderColor` in `src/sway.rs` to avoid invalid `client.focused` runtime criteria syntax.

## Tasks
- [x] Modify `SwayCommand::SetBorderColor` arm in `src/sway.rs` to replace `[con_mark="{}"] border pixel 3, client.focused {}` with `[con_mark="{}"] border pixel 3`.

- Sway does not support `client.focused` as a criteria command.
- Changes restricted strictly to `src/sway.rs` (Files-in-scope).
- Compiler warning for unused `hex_color` field is avoided by using `{ mark, .. }`.
