## Notes
- Toolchain & dependencies: Rust 2024 edition; strictly `serde_json` only (no `serde` derive dependency).
- Manual parsing: `AgentStatus` handles snake_case variants (`idle`, `thinking`, `executing_tool`, `awaiting_human_input`, `completed`), failed object (`{"failed": "<msg>"}`), and fallback string `Other(String)`.
- `AgentWindow` parses required (`id`, `project`, `app_id`, `mark`, `status`) and optional/nullable (`parent_id`, `container_id`) fields while ignoring unknown fields.
- `DiffFrame` requires `snapshot: bool`, `upsert: Vec<AgentWindow>`, and `remove: Vec<String>`.
- `fold_diff_line` returns `false` on any parse error without modifying the map; clears map on `snapshot: true`; applies upserts and removes.
- Zero warnings policy enforced via `cargo clippy --all-targets -- -D warnings`.
- Files in scope: `src/types.rs`, `src/fold.rs`, `src/main.rs` (plus `planning/tasks/35.2.1.todo.md`).
