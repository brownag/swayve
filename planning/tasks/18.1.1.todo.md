# 18.1.1 -- Runtime-Dir Socket and Logs

## Goal
Move the daemon socket and agent logs from world-writable `/tmp` to `$XDG_RUNTIME_DIR/swayve/` (dir 0700, owned by the current user). Refuse to run if `XDG_RUNTIME_DIR` is unset. Stale-socket removal deletes only a socket owned by the current uid.
