- `con_to_agent` lookup is only done in the Sway arm; `next_focus_target` and the `DaemonEvent::Focus` arm are untouched. The destroy-block placeholder arm stays a no-op. `src/sway.rs` untouched.
- Borrow risk: `state.con_to_agent.get` borrows `state` immutably while `last_focused` is a separate local; the clone ends the borrow, so no conflict expected.
- Ordering: events and IPC Focus come via different channels (IPC socket vs event_tx), so the test must wait for each Focus result via `recv_command` before injecting the next event to avoid races. The injected WindowFocused is followed by a short sleep (50ms) before sending Focus.
