# 11.2 — Auto-Spawn Log-Tail Monitoring Windows

## Goal
Auto-spawn companion terminal windows tailing agent log files for registered subagents when `auto_monitor` is enabled, and layout monitor windows side-by-side with subagent windows.

## Tasks
- [x] Add `auto_monitor: bool` field to `DaemonConfig` in `src/config.rs` with default `false`, and add config parsing unit tests.
- [x] Update `src/daemon.rs` to check `auto_monitor` and spawn companion monitor terminal (`foot --app-id agent.monitor.<agent_id> --title "Monitor: <agent_id>" -e tail -f /tmp/swayve/logs/<agent_id>.log` or configured emulator) non-blockingly when a subagent with an active parent is registered or auto-detected.
- [x] Handle `agent.monitor.<agent_id>` window creation in `src/daemon.rs` and update `LayoutManager` in `src/layout.rs` to place monitor windows side-by-side with target agent windows (`MoveToWorkspace`, `SplitHorizontal`, `MoveToContainer`).
- [x] Add unit tests in `src/config.rs`, `src/daemon.rs`, and `src/layout.rs` covering `auto_monitor` configuration, monitor terminal command construction, and side-by-side layout command generation.
- [x] Run `cargo test` to verify all unit and integration tests compile and pass.

## Notes
- **Config**: Added `auto_monitor: bool` to `DaemonConfig` with `#[serde(default = "default_auto_monitor")]` returning `false`.
- **Daemon Spawning**: `std::process::Command::spawn()` is non-blocking. Terminal arguments use `config.terminal.default_emulator` and template `{app_id}`, `{title}`, `{command}`.
- **Layout**: For `app_id` starting with `"agent.monitor."`, `LayoutAction::WindowCreated` emits `MoveToWorkspace`, `SplitHorizontal` on target agent mark, and `MoveToContainer` to target agent mark to position the monitor window side-by-side.
- **Files in Scope**: `src/config.rs`, `src/daemon.rs`, `src/layout.rs`.
