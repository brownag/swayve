# 12.1 — Add Daemon Status Subscription Broadcast

## Goal
Add status subscription support to the daemon IPC interface and broadcast active agent hierarchy state to active subscribers whenever agent registration or status changes occur.

## Tasks
- [x] Add `SubscribeStatus` variant with `#[serde(rename = "daemon.subscribe")]` to `AgentIPCMessage` in `src/types.rs`.
- [x] Add `Subscribe(mpsc::Sender<String>)` variant to `DaemonEvent` and maintain `subscribers: Vec<mpsc::Sender<String>>` in `DaemonState` in `src/daemon.rs`.
- [x] Implement non-blocking `DaemonState::broadcast_status(&mut self)` using `try_send` and retain active subscribers in `src/daemon.rs`.
- [x] Wire `SubscribeStatus` in `handle_client` and trigger `broadcast_status()` in `run_daemon_loops` upon agent registration, status update, subscriber connection, or window destruction.
- [x] Add unit tests `test_subscribe_status_ipc_serde` and `test_daemon_broadcast_status` in `src/daemon.rs`.
- [x] Verify with `cargo check` and `cargo test`.

## Notes
- Files in scope: `src/types.rs`, `src/daemon.rs`.
- Non-blocking broadcast requirement: Subscribers are notified using `mpsc::Sender::try_send` so slow or disconnected clients do not block the daemon processing loop.
- Closed subscriber channels are pruned automatically when `try_send` returns `TrySendError::Closed`.
