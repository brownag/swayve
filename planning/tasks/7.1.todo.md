# 7.1 — Add init-shell CLI Subcommand

## Goal
Add an `InitShell` CLI subcommand to `src/cli.rs` that outputs a POSIX-compliant shell script snippet for bash and zsh to send agent status updates (`idle` and `thinking`) to `$SWAYVE_SOCKET`.

## Tasks
- [x] Add `InitShell` variant with doc comment to `Commands` enum in `src/cli.rs`.
- [x] Add `Commands::InitShell` match arm in `run_cli()` in `src/cli.rs` printing the shell script snippet.
- [x] Verify with `cargo run -- init-shell`.
- [x] Add unit test `test_init_shell_cmd_parsing` in `src/cli.rs` testing `Commands::InitShell` output / parsing.
- [x] Run `cargo test` to verify all tests pass cleanly.

## Notes
- Files in scope: `src/cli.rs` ONLY.
- Grep Anchors: `pub enum Commands` in `src/cli.rs`, `run_cli` in `src/cli.rs`.
- Output script detects `SWAYVE_SOCKET` and `SWAYVE_AGENT_ID`, checks for unix socket presence, and uses `nc -U` or `socat` to send JSON `agent.update_status` IPC payload.
- Uses `2>/dev/null || true` to gracefully swallow connection or execution errors.
- Hooks into `zsh` via `add-zsh-hook` (`precmd`/`preexec`) and `bash` via `PROMPT_COMMAND` / `DEBUG` trap with `_swayve_in_precmd` re-entrancy prevention.
