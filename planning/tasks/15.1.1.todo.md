# 15.1.1 -- Report Malformed Config on Stderr

## Goal
Make `load_config()` print a `[config] ...; using defaults` line to stderr when the config file exists but is unreadable or malformed, via a testable `parse_config_file` helper.

## TODO items
- [x] Add `pub fn parse_config_file(path: &Path) -> Result<Option<Config>, String>` above `load_config` in `src/config.rs`: `fs::read_to_string`; on `ErrorKind::NotFound` return `Ok(None)`; other read errors -> `Err(format!("{}: {}", path.display(), e))`; `toml::from_str` error -> `Err(format!("{}: {}", path.display(), e))`; success -> `Ok(Some(cfg))`.
- [x] Rewrite `load_config()`: HOME unset -> `Config::default()`; path `$HOME/.config/swayve/config.toml` (same format string); match helper: `Some(c)` -> c, `None` -> default silently, `Err(msg)` -> `eprintln!("[config] {}; using defaults", msg)` + default. Signature unchanged.
- [x] Add test `test_parse_config_file_malformed_reports_path` in existing `mod tests` (after `test_hooks_config_default`): write `daemon = [` to `std::env::temp_dir()/swayve-config-test-<pid>.toml`, call helper, assert `Err` and message contains `path.display().to_string()`, remove file.
- [x] Run `cargo test --lib config::` and confirm all pass.

## Notes
- Current `load_config` silently swallows read/parse errors (nested `if let`); `PathBuf`, `fs`, `toml` already imported in config.rs (`std::path::Path` may need adding to imports, or use full path in signature as in spec).
- Using NotFound match instead of `path.exists()` avoids a TOCTOU gap; a permission-denied file now reports an error, which matches the spec ("cannot be read").
- No new deps; unique temp name uses process id (tests in this module run in one process, only one test uses this name).
- Config/HooksConfig/defaults untouched; src/cli.rs untouched.
