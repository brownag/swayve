## Notes
- Diff line shape (src/daemon.rs broadcast_diff): `{"snapshot":bool,"upsert":[AgentWindow],"remove":[AgentId]}`; AgentId serializes as a plain string (AgentWindow.id), so remove entries are strings.
- Diff subscriber gets nothing on subscribe; first line arrives at the next broadcast_status (the first Register), as a snapshot.
- Removal: no agent.deregister IPC exists. Only path is `SwayEvent::WindowDestroyed` via `DaemonEvent::Sway`, which needs `con_to_agent` populated by a prior `WindowCreated` with app_id `agent.pi.<id>` (register_agent_window); it then removes the agent and calls broadcast_status. I will use that (event_tx is public in tests, already used at lines 163/309).
- Daemon state has no direct query. Final comparison uses a second `daemon.subscribe` stream, whose first line is the full list at subscribe time (independent of the diff path). Not the diff stream's own snapshot.
- Expected agents after removal: 2.
- Intermediate lines may be coalesced/ordered per broadcast; the map is checked only after convergence, not per-line.
