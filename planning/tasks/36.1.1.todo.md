## Notes
- Only `.opencode/plugins/swayve.ts` and sourced corrections to `planning/RESEARCH_OPENCODE_INTEGRATION.md` may be changed; `.development/` is scratch only.
- Do not add dependencies, tests, Rust/protocol changes, docs for Wave 2, or unrelated edits. No state-changing commands before approval.
- Official docs establish `Plugin.define`, `setup(ctx)`, `ctx.event.subscribe({ types, signal })`, async iterable events, cleanup abort, and no `server.connected` in server plugins. Event schema details/version still need pinning.
- Swayve IDs are plain strings in `AgentId`; wire statuses are `idle`, `thinking`, `executing_tool`, `awaiting_human_input`, `completed`, or `{failed: string}`. Registration requires `agent_type`, `project_id`, numeric `pid`, `app_id`, and nullable `parent_agent_id`.
- Exact test command required by Task 36.1.1 is not specified; targeted Node syntax/load verification is planned, with mock-socket tests deferred to Wave 2.
