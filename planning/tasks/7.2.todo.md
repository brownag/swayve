Establish the `integrations/` directory structure with bootstrapping documentation and scripts for Pi, Claude, and Antigravity integrations with Swayve.

## Notes
- Files in scope: `integrations/pi/README.md`, `integrations/claude/claude-wrapper.sh`, `integrations/antigravity/README.md`.
- Constraints honored: Proper shebang (`#!/usr/bin/env bash`) and executable permissions on `claude-wrapper.sh`.
- IPC Schema: Follows `agent.register` (with `agent_id`, `agent_type`, `project_id`, `pid`, `app_id`, `parent_agent_id`) and `agent.update_status` (with `agent_id`, `status`) over Unix domain socket `$SWAYVE_SOCKET`.
- Graceful error handling: Wrappers use `nc -U` with fallbacks or condition checks so failure to connect to `$SWAYVE_SOCKET` does not break agent command execution.
