## Notes
- `handle_client` matches Hazard Notes: blank lines skipped, parse errors are logged and the loop continues, `AgentIPCMessage::Focus` sends `DaemonEvent::Focus`. Non-UTF-8 closes client; tests use ASCII only.
- `start_daemon_ipc` removes a socket only if `is_socket()` and uid equals `current_uid()`; unchanged.
- Subtlety: the stale file is already a socket before the daemon runs, so the poll could pass before removal and rebind. Mitigation: after the poll, also check that a `std::os::unix::net::UnixStream::connect(path)` succeeds (stale socket refuses with ConnectionRefused), so the test actually proves replacement. I will poll on a successful connect plus `is_socket()`. The spec says only `is_socket()`; this is a small strengthening, not a scope change.
- `DaemonEvent` does not derive `Debug`/`PartialEq` (it holds a Sender), so use `matches!`, not `assert_eq!`.
- Acceptance command `cargo test --lib test_stale_socket_same_owner test_malformed_ipc_line` is invalid cargo syntax (multiple filters need `--`); I will run the two targeted commands separately.
- Only `mod tests` edited; `AsyncWriteExt` import needed locally for `write_all`.
