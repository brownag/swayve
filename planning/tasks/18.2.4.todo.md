## Notes
- There is NO `to_command_string`-style method. Rendering is an inline `match &cmd` inside `SwayManager::run_executor` at `src/sway.rs:43-68`, producing `command_str`. Enum is at `src/sway.rs:8-17` (8 variants).
- Production logic may not change, so the test cannot call a helper. Options are in Questions.
- Exact strings (from `src/sway.rs:44-67`):
  - MarkWindow -> `[con_id="7"] mark --add "m"`
  - SetBorderColor -> `[con_mark="m"] border pixel 3` (hex_color ignored)
  - FocusWindow -> `[con_mark="m"] focus`
  - MoveToWorkspace -> `[con_id="7"] move container to workspace w`
  - ApplyLayout -> `[workspace="w"] layout l`
  - SplitHorizontal -> `[con_mark="p"] focus, split horizontal`
  - MoveToContainer -> `[con_id="7"] move container to mark "t"`
  - SetLayoutTabbed -> `[con_mark="m"] layout tabbed`
- `AgentStatus` (`src/types.rs:19-28`): derives `Debug, Clone, PartialEq, Eq, Serialize, Deserialize`, `#[serde(rename_all = "snake_case")]`, externally tagged, so `Failed(String)` serializes as `{"failed":"..."}`. PartialEq allows `assert_eq!` on round-trip.
- `AgentId::to_mark` at `src/types.rs:7-9` is `mark_` + id with `-` replaced by `_`; `to_children_mark` at `:11-13`.
- `serde_json` is already a dependency (used in `types.rs:53`).
