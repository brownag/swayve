## Notes
- Socket path resolution: `$SWAYVE_SOCKET` takes precedence unless unset or empty (`""`), falling back to `$XDG_RUNTIME_DIR/swayve/swayve.sock`. Returns clean error if neither is set.
- Handshake protocol: sends exact wire string `{"method":"daemon.subscribe_diff"}\n` upon connection and flushes.
- Resilient backoff: 500ms initial delay, doubling up to 5000ms max on connection error or EOF/stream error; reset to 500ms on valid frame receipt; no tight spinning.
- ANSI rendering: `\x1b[2J\x1b[H` screen clear, header `=== Swayve HUD (Live Agents: <count>) ===`, agent list sorted by `id` showing status, id, app_id, project, mark.
- Non-JSON / malformed line safety: skipped silently without screen clear or re-render when `fold_diff_line` returns `false`.
- Crate structure: `src/lib.rs` re-exporting `types`, `fold`, and `client` to avoid duplication and cleanly support Wave 4's integration test.
- Constraints: standard library blocking `UnixStream` only (no async runtime), `serde_json` only, zero compiler/clippy warnings.
- Files in scope: `src/lib.rs`, `src/client.rs`, `src/main.rs`, and `planning/tasks/35.3.1.todo.md`.
